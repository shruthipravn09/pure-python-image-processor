# pure-python-image-processor
#Grayscale (output_gray.ppm)
Converts the image to grayscale. It transforms a full-color image into shades of gray. It uses the weighted luminosity formula.

#Horizontal Flip/Mirror image (output_flipped.ppm)
It flips the image. Reverses the column positions of pixels within every row of the image matrix, creating a mirror effect. 

#Brightness adjustment (output_bright.ppm)
Increases or decreases the intensity of every RGB channel. Color values are clamped strictly within 0 to 255 range.
